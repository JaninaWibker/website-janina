Unstructured, unpolished, and unbothered, but ever-evolving.

Ideally this is but a place for me to quickly write down or refine some ideas, notes, and thoughts, without having to adhere to a strict format, structure, quality, or style which I'd maybe otherwise impose on myself without there being an actual reason to it.

A core difference to what you'd expect from blog posts is an inherent lack of completeness in the sense that things get repeatedly updated to include new thoughts and experiences, instead of being confined to only topics that allow for a done state.
Blog posts can receive updates and corrections, but they are at their core meant to be in a done state, whereas for example a "reading list" is never expected to be in a final state, but is rather ever-evolving and changing.
